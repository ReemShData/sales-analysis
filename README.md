# Sales Analysis Project

## Overview
This project analyzes sales data for 3 products across 6 months and 4 regions.

## Tools Used
- Microsoft Excel

## Dataset
- 18 rows of sales data
- Products: Laptop, Phone, Headphones
- Regions: North, South, East, West
- Period: January 2024 - June 2024

## Key Findings
- Total Revenue: $359,500
- Best Month: June ($79,000)
- Best Selling Product: Laptop
- Total Units Sold: 1,090

## Files
- sales_analysis.xlsx : Raw data and analysis with charts
